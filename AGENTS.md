# Правила работы

- Делать частые, мелкие коммиты (после каждого осмысленного изменения) с понятным сообщением, чтобы можно было легко откатиться. Push после коммитов.
- Стек: Minecraft 1.21.11, Meteor 1.21.11-SNAPSHOT, loom 1.14.10, yarn mappings `1.21.11+build.3`, Java 21. Код пишется на yarn-именах (не mojmap).
- Тесты: `.\gradlew.bat build` (таск `check` запускает `runUnitTests`). Штатный Gradle-таск `test` отключён (кварк loom+worker).
- При кике/ошибке пользователя собирать: точный текст кика, `logs/latest.log` из папки .minecraft, trace-вывод модуля (настройка `debug-trace`), данные сервера (платформа, версия Grim).
